Sistema de gestión de PROYECTOS

El objetivo de esta página web es poder llevar una administración financiera y la gestión de varios proyectos en paralelo para un equipo de desarrolladores.

En el sistema se deben poder gestionar los CRUD de:
- Proyectos: id_proyecto, Nombre, Descripción, Estado, Gastos, Cliente, Presupuesto, Desarrolladores asignados, Plazo de entrega (días, semanas, meses), Fecha de inicio y Fecha de finalización.
- Clientes: id_cliente, Nombre, Estado (Activo/Inactivo) y Fecha de alta.
- Desarrolladores: id_desarrollador, Nombre y apellido, e Ingresos (mensuales, anuales).
